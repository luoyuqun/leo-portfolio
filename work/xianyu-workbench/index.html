Windows 工具 AI 客服 自动交付

闲鱼 AI 客服与自动发货工作台

将多账号接待、商品资料、兑换码库存和自动交付整合到一个工作台，重复问题交给 AI，需要人工时及时提醒。

类型 Windows 本机应用
角色 产品化开发
技术 Python / JS / SQLite
年份 2026

项目介绍

面向闲鱼卖家的本机客服与数字商品交付工具。通过网页管理多个账号，按商品配置接待资料和发货内容，把重复咨询、库存分配与人工提醒串成一套流程。

要解决的问题

  • 多个账号来回切换，商品资料容易混淆
  • 买家重复提问，需要反复发送相同答案
  • 兑换码和下载链接靠手动发，难以追踪库存
  • 需要人工接手时，消息容易遗漏

实现方式

账号和商品分开管理，扫码连接店铺后在后台自动同步商品。AI 根据卖家确认的资料接待，付款核验通过后按配置交付文字内容；遇到退款、答复不确定或需要进一步沟通的情况，提醒卖家接手。

接待流程

支持灵活配置接待策略：AI 持续接待、有明确意向后转人工、先回复一条再转人工，也可只提醒或暂停。

主要功能

👤

多账号管理

扫码添加账号，获取昵称与头像，按账号查看商品和运行状态。

🔄

商品自动同步

后台定期更新目录，失败保留已有列表；详情支持图片，视频展示取决于接口是否返回可用地址。

💬

灵活接待

AI 持续接待、有明确意向后转人工、先回复一条再转人工，也可只提醒或暂停。

⚙️

自定义资料

按店铺和商品配置说明、常见问题答复及回复风格。

📦

数字内容交付

兑换码、下载地址、网盘链接等文字内容；付款和订单条件通过核验后才执行自动交付。

🔗

共享库存

一个库存可绑定多个卖家账号和商品，分配记录可追踪，未分配的码可删除。

🔔

人工提醒

支持钉钉、企业微信、飞书通知；退款与退货交由卖家确认处理。

🖥️

Windows 安装版

安装后打开本机网页后台，包含管理密码修改和新版检测提醒。

产品设计

采用黄色作为主要强调色，将账号、商品、客服答复、库存发货和系统设置分成独立模块。桌面端导航固定，主要内容独立滚动；复杂配置使用弹窗，帮助卖家逐步完成设置。

技术与交付

Python 后端、原生 JavaScript / HTML / CSS 管理界面、SQLite 本地存储、Windows 安装包。模型通过兼容接口接入，通知由对应平台接口发送。

项目基于 XianyuAutoAgent 开源项目继续开发与产品化，保留 GPLv3 许可证及对应源码。

当前状态与使用条件

已提供 0.2.4 Windows 安装版。需要 Windows 10/11 64 位电脑保持开机联网，以及使用者自己的闲鱼账号、AI API 密钥；模型调用费用由服务商另计。自动交付需配置商品、库存、内容及开关。

此页面是项目展示，不是在线演示。尚未完成软件收费日卡/周卡/月卡授权平台、工作台直接发布闲鱼商品、软件自动下载安装更新。

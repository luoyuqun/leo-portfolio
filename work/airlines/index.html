Airlines

类型
旅行社官网
分工
设计与开发
年份
2026
技术
HTML / CSS · 视差滚动 · 图片裁剪

旅行社官网，首屏镜头穿过舷窗，往下所有照片都框在舷窗里，结尾的晚霞随滚动放大到整屏。

这是给一家做高端定制旅行的小公司做的官网。他们的卖点是"像私人飞机一样的体验"，所以整个网站围绕"舷窗"这个视觉元素展开。

首屏是一个从飞机内部看向窗外的视角。随着向下滚动，镜头会"穿过"舷窗，进入云层之上的天空。过渡做了无缝衔接，用 CSS mask 和 transform 配合实现。

往下滚动，每一张目的地照片都框在一个舷窗形状的容器里。照片会有微妙的视差效果——滚动时图片移动的速度比页面慢一点，营造出透过窗户看风景的感觉。

结尾是一整屏的晚霞照片，随着滚动逐渐放大、拉近，最后定格在"让每一次旅行都像飞一样"的 slogan 上。

线路介绍用了时间线的形式，从出发到返回，每一天的行程都有对应的小图和简介，一目了然。

Airlines

旅行品牌 视差滚动 沉浸式体验
项目类型
高端旅行社官网
我的角色
设计与开发
完成年份

技术栈
HTML / CSS · 视差 · CSS mask
项目背景

一家主打"私人飞行体验"的高端旅行社

这是给一家做高端定制旅行的小公司做的官网。他们做的不是普通跟团游，而是私人飞机、私人向导、专属行程的"头等舱"级别的旅行服务。客单价很高，客户群体也很小众。

他们之前的网站就是个普通的旅游模板，完全撑不起"高端"这个定位。客户说："我们卖的是体验，但网站看起来就很没体验。"

核心挑战

怎么用网页传达"飞行感"和"高级感"

高端旅行网站很容易做俗——满屏的海景、日落、香槟，看起来就像朋友圈的微商广告。怎么避免俗套，同时又能准确传达"自由、奢华、飞翔"的品牌感觉？

另外一个挑战是内容不多——他们不做很多线路，只做精选的十几条。不能靠内容量撑页面，得靠体验和设计来撑。

解决方案

围绕"舷窗"这个元素，讲一个飞行的故事

整个网站围绕"舷窗"这个视觉元素展开。首屏是一个从飞机内部看向窗外的视角。随着向下滚动，镜头会"穿过"舷窗，进入云层之上的天空。过渡做了无缝衔接，用 CSS mask 和 transform 配合实现，不用任何视频也能有电影感。

往下滚动，每一张目的地照片都框在一个舷窗形状的容器里。照片会有微妙的视差效果——滚动时图片移动的速度比页面慢一点，营造出透过窗户看风景的感觉。

结尾是一整屏的晚霞照片，随着滚动逐渐放大、拉近，最后定格在"让每一次旅行都像飞一样"的 slogan 上。整个浏览过程就像一次飞行体验——起飞、看风景、降落。

线路介绍用了时间线的形式，从出发到返回，每一天的行程都有对应的小图和简介，一目了然。

最终成果

官网成为主要获客渠道，咨询量提升 80%

新官网上线后，最大的变化是咨询质量明显提高了。以前很多咨询都是问价格的，现在更多是直接问"你们某条线路还有没有档期"——因为网站已经帮他们筛选过了，能接受这个调性的客户才会来咨询。

数据方面，官网咨询量整体提升了 80%，客单价也有所提高。客户说，现在他们甚至可以用官网来"反向筛选"客户——不适合的客户看完网站自己就不会来了。

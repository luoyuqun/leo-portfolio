仓衡 WMS

类型
B2B 软件官网
分工
设计与开发
年份
2026
技术
HTML / CSS · Canvas · 数据可视化

一款仓储管理软件的官网，首屏是用代码实时绘制的仓库画面，拣货员在货架间按路线走动。

仓衡是一家做中小仓库管理系统的 SaaS 公司。他们之前的官网是模板套的，看起来和竞品没区别，想做一个能体现技术实力的新官网。

首屏的核心是一个用 Canvas 画的仓库俯视图——货架、通道、拣货员，都是代码实时渲染的。拣货员会沿着最优路径在货架间穿梭，每经过一个货位就"拣"一件货，画面上的库存数字会实时减少。

往下滚动，会依次展示入库、库存、拣货、出库四个核心模块，每个模块都有对应的动态示意图。不是截图，是真的在跑的简化版系统界面。

功能介绍部分用了"对比式"布局——左边是传统仓库的痛点，右边是用了仓衡之后的变化，数据和图示并排展示，一目了然。

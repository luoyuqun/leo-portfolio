仓衡 WMS

B2B SaaS 数据可视化 Canvas
项目类型
B2B 软件官网
我的角色
设计与开发
完成年份
2026
技术栈
HTML / CSS · Canvas
项目背景

一款想从竞品中跳出来的仓储管理 SaaS

仓衡是一家做中小仓库管理系统的 SaaS 公司。他们的产品其实挺好用的，但之前的官网是套的模板，看起来和市面上几十个 WMS 竞品没什么区别——都是蓝色科技风、都是同样的模块图标、都是差不多的话术。

客户的需求很明确：做一个能体现技术实力的新官网，让访客一进来就觉得"这家公司有点东西"。

核心挑战

B2B 官网怎么不无聊，又不能太花哨

B2B 软件官网的困境是：太朴素了显得没实力，太花哨了又不专业。尤其是仓储管理这种偏传统的行业，客户都是务实的仓库经理和老板，花里胡哨的东西他们不信。

怎么找到一个平衡点——既能展示技术能力，又能让目标客户觉得"这就是我需要的"？

解决方案

让产品自己"动"起来说话

首屏的核心是一个用 Canvas 画的仓库俯视图——货架、通道、拣货员，全都是代码实时渲染的。拣货员会沿着最优路径在货架间穿梭，每经过一个货位就"拣"一件货，画面上的库存数字会实时减少。这不是视频，是真的在跑的算法演示。

往下滚动，依次展示入库、库存、拣货、出库四个核心模块，每个模块都有对应的动态示意图——不是截图，是简化版的系统界面在真实运行。

功能介绍部分用了"对比式"布局——左边是传统仓库的痛点（手写单、找货慢、库存不准），右边是用了仓衡之后的变化，数据和图示并排展示，一目了然。

最终成果

Demo 申请转化率提升 65%

新官网上线后，最直接的变化是 demo 申请转化率从 3.2% 提升到了 5.3%，增长了 65%。客户反馈说，很多新客户打来电话的第一句话都是"你们官网那个仓库动画挺有意思的"。

在销售跟进中，官网也成了很好的"破冰"话题——客户愿意聊，就更容易推进到下一步。

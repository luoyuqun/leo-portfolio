焙序咖啡

品牌官网 创意动效 SVG 动画
项目类型
咖啡品牌官网
我的角色
设计与开发
完成年份
2026
技术栈
HTML / CSS · SVG · rAF
项目背景

一家想从朋友圈走向品牌的精品咖啡店

客户是一家做精品咖啡豆烘焙的小店，之前主要靠朋友圈和小红书卖豆子，生意不错但总觉得"不够正式"。他们想做一个真正的品牌官网——不是为了卖货（主要渠道还是私域），而是为了建立品牌形象，让新客户一眼就能感受到他们的专业和用心。

预算有限，也没有设计师，所以从策略到视觉到代码都是我一个人搞定。

核心挑战

怎么用网站传达"烘焙"这件事的温度

咖啡店的官网很容易做成模板——放几张咖啡拉花的图，写几段文艺的话，看起来都差不多。焙序的核心差异是"自家烘焙"，但"烘焙"这个过程是动态的、有温度的，怎么在一个静态网站上体现出来？

另外一个挑战是手机端体验。他们的客户很多是通过朋友圈链接打开的，手机端体验必须足够好，不能只是桌面端的缩小版。

解决方案

把烘焙曲线变成首屏的主角

网站的核心创意是把"烘焙"这个过程可视化。首屏用 SVG + requestAnimationFrame 实时画出一条烘焙温度曲线——随着页面加载，曲线从生豆状态一路爬升，经过一爆、二爆，最后落到成品豆的颜色。背景色也会跟着曲线的温度从冷变暖。

豆单页面没有用传统的表格，而是把每款豆子做成了真实的豆包标签样式——有产地、海拔、处理法，还有风味轮盘。鼠标悬停时标签会微微翘起，像真的从货架上拿起来一样。

整站用纯 HTML/CSS/JS 实现，没有框架，加载很快。手机端做了完整适配，烘焙曲线在小屏幕上会变成纵向滚动，豆包标签换成单列布局。

最终成果

上线一个月，线上订单增长 40%

网站上线后，客户最大的感受是"发出去有面子了"——以前给新客户介绍只能发朋友圈截图，现在发一个官网链接，信任感立刻不一样。

数据方面，上线第一个月通过官网来的新客户占比达到 25%，线上订单整体增长了 40%。手机端跳出率只有 35%，远低于行业平均水平。

stories in light

类型
摄影师作品集
分工
设计与开发
年份
2026
技术
HTML / CSS · Canvas · 鼠标追踪

摄影师作品集网站，鼠标就是手电筒——光斑滑过人像，照到的地方露出金色面具和暗纹墙纸。

这是给一位时尚摄影师做的个人作品集。她的作品风格偏暗调、戏剧化，很多照片都有强烈的光影对比。

首屏的创意是"黑暗中的一束光"——整个页面几乎是黑的，只有鼠标（或手指）所在的位置有一个圆形光斑。移动鼠标，光斑会跟着走，照到的地方才会显示出照片的细节。

技术上用了两层图片叠加：底层是正常的照片，上层是一张调暗的蒙版。通过 Canvas 的 clip 功能，把鼠标位置的圆形区域"挖空"，露出底下的原图。光斑边缘有自然的羽化过渡，不会显得生硬。

作品集页面用了瀑布流布局，但不是传统的 masonry，而是每一行高度一致的"画廊墙"风格。点击照片会打开全屏查看器，左右滑动切换，支持键盘操作。

关于页用了打字机效果，摄影师的自述一段一段地"写"出来，配合光标闪烁，很有氛围感。
